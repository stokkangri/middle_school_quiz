Edits that usually round-trip
  • Numbers, signs, and simple math (* 0.5, Range.clip, Math.abs, stick axes)
  • Extra setPower / sleep / telemetry / setZeroPowerBehavior lines
  • if / else if / while using gamepad or opModeIsActive
  • Locals: double / int / boolean / String assignments

Avoid new classes, vision, threads, Road Runner, switch, lambdas — those stay in Java (or a myBlock).
