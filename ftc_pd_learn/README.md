# Steer Straight — FTC PD Control Lab

Interactive web page for middle-school FTC students learning **proportional (P)** and **differential (D)** control.

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Put this folder in a GitHub repo (as the repo root, or in `/docs`).
2. **Settings → Pages → Deploy from branch**
3. Choose branch + `/` (root) or `/docs`

Site URL will be like `https://YOURUSER.github.io/REPO/`

## Deploy to Netlify

1. Drag this folder onto [Netlify Drop](https://app.netlify.com/drop), **or**
2. Connect the repo; set publish directory to `ftc_pd_learn` (or `.` if this folder is the repo root).

No build step required — static HTML/CSS/JS only.
